# AI Learning Assistant

## Overview
AI Learning Assistant detects student emotions from text and provides personalized learning support.

## Features
- Emotion Detection
- AI Suggestions
- CSV Logging
- Analytics Dashboard
- BiLSTM / BERT Model Selection

## Technologies Used
- Python
- Streamlit
- Pandas
- Plotly
- TensorFlow
- Google Gemini API

## Run the Project

```bash
streamlit run app.py
```
